# 0002. 묶음 비교는 관측 범위 겹침으로 판정한다

상태: 채택 · 2026-10-18

## 맥락

이 저장소의 비교 화면과 측정 계약은 "단일 실행은 통계적 근거가 아님"을 반복해서 경고한다. 반복 측정을 도입해도 반복 수는 보통 3–10회이고 실행은 같은 기계에서 순서대로 이뤄져 독립 표본 가정이 약하다. t-검정 같은 유의성 검정을 붙이면 근거보다 강한 결론처럼 읽힌다.

## 결정

- 성공한 측정 반복이 어느 쪽이든 3회 미만이면 `INSUFFICIENT`.
- 두 묶음의 관측 범위(min–max)가 겹치면 `OVERLAPPING`(차이 불분명), 모든 반복이 상대 범위 밖이면 `SEPARATED`.
- 회귀 판정은 중앙값 변화가 허용 오차를 넘고 `SEPARATED`일 때만 방향을 본다. 측정 계약에 방향이 없으므로 `elapsed`(낮을수록 좋음)와 `throughput`(높을수록 좋음)만 코드에 명시하고, 나머지는 `CHANGED`로 실패 처리한다.
- p95는 nearest rank로 실제 관측값 중 하나를 보고한다.

## 결과

- 오탐(노이즈로 인한 회귀 판정)은 줄고, 작은 실제 변화는 놓칠 수 있다. 민감도를 높이려면 반복 수를 늘린다.
- 판정 이름과 화면 문구가 유의성 검정이 아님을 명시한다. 더 강한 통계가 필요해지면 새 ADR로 바꾼다.
