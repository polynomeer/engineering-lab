# 설계 결정 기록 (ADR)

되돌리기 어렵거나 이후 작업의 전제가 되는 결정을 하나씩 남긴다. 설계·계획 문서는 진행 기록이고, 현재 동작은 사용·운영·API 문서와 코드가 기준이다.
